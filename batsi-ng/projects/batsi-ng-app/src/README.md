# BaTsiNgApp

## Info

The Angular frontend.

## Setup

- Copy the [environment.ts](./environments/environment.ts) and rename it to `environment.develop.ts`
    - Set `apiBaseUrl: 'http://127.0.0.1:8787'` (must match proxy base URL)
    - Set `apiToken: <TOKEN>` (replace \<TOKEN> with the token generated in [Proxy](../../../../batsi-oebb-proxy/README.md))
