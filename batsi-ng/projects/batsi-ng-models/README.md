# BatsiNgModels

## Info

The auto-generated backend models for usage with the bATsi Angular frontend.

## Setup

### OpenJDK

OpenJDK is required to be able to run the OpenAPI generator.

- Get OpenJDK from https://learn.microsoft.com/en-us/java/openjdk/download
- Extract / run installer
- Set "JAVA_HOME" environment variable to installation path

### Install

- Install 3rd party dependencies by running:
  - `npm install`

### Generate models

- Start generation of models by running:
  - `npm run build:models`
