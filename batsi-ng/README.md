# BatsiNg

## Info

The bATsi frontend workspace.

### Projects

Refer to the Readmes of the projects on how to build them.

The order matters, first build the models, build the frontend app afterwards.

- [bATsiNgModels](./projects/batsi-ng-models/README.md)
  - The BFF models used in the frontend
- [bATsiNgApp](./projects/batsi-ng-app/README.md)
  - The Angular application

## Setup

### Install

- Install 3rd party dependencies by running:
  - `npm install`

## Testing

[Jest](https://jestjs.io/) ist used as test runner.

Run `npm run test:batsi-ng-app` to run the frontend tests.
